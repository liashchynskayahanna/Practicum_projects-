# Проверка гипотез и анализ A/B-теста

## Описание проекта

В проекте проведен анализ пользовательской активности в сервисе чтения и прослушивания книг, а также оценена эффективность изменений интерфейса интернет- магазина на основе результатов A/B- тестирования.

Работа включает статистическую проверку гипотез, расчет продуктовых метрик и анализ поведения пользователей.

---

## Цель проекта

- Проверить гипотезу о различиях во времени активности пользователей из Москвы и Санкт-Петербурга  
- Рассчитать ключевые продуктовые метрики (MAU, LTV, активность пользователей)  
- Оценить корректность проведения A/B-теста  
- Определить влияние нового интерфейса на конверсию в покупку  

---

## Основные задачи

- Предобработка и исследовательский анализ данных  
- Проверка статистической гипотезы с использованием t-теста  
- Анализ распределения пользователей по группам A/B-теста  
- Расчет конверсии и оценка результатов эксперимента  

---

## Используемые инструменты

- Python  
- Pandas  
- NumPy  
- SciPy (статистические тесты)  
- Matplotlib / Seaborn  
- Jupyter Notebook  

---

## Результат

- Проверена статистическая значимость различий в пользовательской активности  
- Проанализирована корректность проведения A/B-теста  
- Оценено влияние нового интерфейса на бизнес-метрики  

Проект демонстрирует навыки анализа продуктовых данных, статистического тестирования и интерпретации результатов экспериментов.
