
## Описание проекта

В проекте проведен исследовательский анализ данных сервиса продажи билетов на мероприятия.  
Цель — выявить изменения в пользовательском поведении, определить факторы роста и снижения продаж, а также подготовить аналитические выводы для продуктовой команды.

В рамках работы выполнены:

- исследовательский анализ пользовательской активности и продаж  
- анализ популярности событий, организаторов и площадок  
- сравнение поведения пользователей мобильных и десктопных устройств  
- проверка статистической гипотезы о различиях в активности пользователей  
- разработка аналитического дашборда для мониторинга ключевых метрик
